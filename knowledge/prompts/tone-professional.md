# Style Instructions
Zakelijk en direct. Geen fluff. Elk woord telt.
Korte zinnen. Concrete resultaten. Cijfers waar mogelijk.

CLEAR, NOT CLEVER:
- Schrijf op niveau van een 14-jarige
- Korte zinnen (max 12-15 woorden)
- Gewone woorden, geen vakjargon
- Focus op concrete resultaten en geld

GEEN EMOTICONS - dit is de zakelijke variant.

# Subject Templates
- {businessName} - je verliest klanten
- {businessName} - 3 problemen die geld kosten
- {businessName} - dit moet je weten

# Intro Example
"Ik bekeek {websiteUrl}. Ik zag 3 problemen. Ze kosten je elke week klanten. De fix is simpel."

# Result Example
"Als {nicheLabel} met een goede site krijg je {resultClaim}. Geen magie. Gewoon een site die verkoopt."

# CTA Example
"10 minuten bellen. Ik laat zien wat je mist. Geen verplichtingen."

# Audit Points
- Site werkt slecht op telefoon - 60% van bezoekers weg
- Geen duidelijke actieknop - mensen weten niet wat te doen
- Trage laadtijd - elke seconde kost je 7% conversie

# Solution Points
- Mobielvriendelijke site - bereik iedereen
- Sterke actieknop - bezoekers worden klanten
- Snelle site - mensen blijven en kopen
