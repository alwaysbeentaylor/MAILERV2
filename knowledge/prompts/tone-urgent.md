# Style Instructions
Urgentie. Elke dag wachten = geld verliezen.
Niet schreeuwerig. Maar wel duidelijk: dit kost je geld. Nu.

CLEAR, NOT CLEVER:
- Niveau van een 14-jarige
- Korte zinnen die raken
- Focus op wat ze VERLIEZEN (niet wat ze kunnen winnen)
- Maak het concreet en urgent

EMOTICONS GEBRUIKEN! ⚠️🔥💸 Urgentie voelbaar maken.

# Audit Points
- ⚠️ Site kapot op mobiel - 60% van je bezoekers ziet een puinhoop
- 🚨 Geen actieknop - mensen willen kopen maar kunnen niet
- 💸 Trage site - elke seconde vertraging = 7% minder verkoop

# Solution Points
- ⚡ Werkende mobiele site = stroom aan klanten terug
- 🎯 Sterke actieknop = bezoekers worden betalers
- 🚀 Snelle site = meer verkoop, minder afhakers
